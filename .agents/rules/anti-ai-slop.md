# Rule: Anti-AI-Slop Design & Precision Standards

Every design and UI modification in this repository must comply with the guidelines defined in `DESIGN.md` and the `anti-slop-design` skill:

1. **Token Adherence:** Use exact tokens from `DESIGN.md` (`#F5F5F7` canvas, `#FFFFFF` cards, `#1D1D1F` text, `#FF385C` Airbnb coral accents, `#0071E3` Apple blue).
2. **Apple Keynote Brevity:** Keep copy concise, active, and punchy. Eliminate wordy marketing fluff and passive explanations.
3. **8px Grid Discipline:** Strictly avoid arbitrary pixel padding or margins. Snap to the 8px grid system.
4. **Single Visual Star WebGL:** Maintain 60fps performance by ensuring WebGL loops pause when inactive or off-screen and clean up geometries/materials on unmount.
5. **Optical Contrast:** Ensure all copy meets WCAG AA / AAA contrast standards.
